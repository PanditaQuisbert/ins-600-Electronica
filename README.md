## 📖 Descripción

**TechStore** es una landing page moderna y responsive para una tienda de electrónica. Construida con **HTML5**, **Tailwind CSS** y **JavaScript vanilla**, ofrece una experiencia de usuario premium con modo oscuro, carrito funcional, filtros de productos y animaciones suaves.

## 🚀 Características

- ✅ **Diseño 100% Responsive** - Adaptado a móvil, tablet y desktop
- 🌙 **Modo oscuro** con persistencia en localStorage
- 🛒 **Carrito de compras funcional** con modal interactivo
- 🔍 **Filtros de productos** por categoría
- ⏰ **Countdown dinámico** para ofertas
- 📱 **Menú móvil** con animaciones
- 🎨 **Animaciones suaves** y efectos hover
- 💬 **Botón flotante de WhatsApp**
- ⬆️ **Botón scroll to top**
- 🔔 **Notificaciones toast**
- 📧 **Newsletter funcional**
- ♿ **Accesibilidad mejorada** (aria-labels)
- ⚡ **Optimizado para SEO** (meta tags, Open Graph)
- 🖼️ **Lazy loading** en imágenes
- 🎯 **Loader inicial** profesional
